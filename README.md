# cold_email
This is python based cold email automatic sending for your job application.


How to use it:
- Change to your email
- Change to your app password, not your e-mail password, here's how :
    1. Enable 2-Step Verification first (if you haven't already)
        Go to https://myaccount.google.com/security → look for "2-Step Verification" → enable it. This is a mandatory prerequisite for generating an App Password.

    2. Generate an App Password
        Go to https://myaccount.google.com/apppasswords (you must be logged in). If the link doesn't appear or results in an error, it is usually because 2-Step Verification           is not enabled.
        Give it a name of your choice, e.g., "python-script"
        Click Create
        Google will provide a 16-character code (e.g., abcd efgh ijkl mnop)
- List your database of company email and company name
- Go crazy
